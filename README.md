# Estem Dental Clinic — Премиальная стоматология в Астане

Этот репозиторий содержит исходный код официального веб-сайта стоматологической клиники **Estem Clinic**. Сайт представляет собой лендинг с детальными страницами по каждой услуге, интерактивным прайс-листом и квизами для сбора заявок. 

Дизайн выполнен в премиальном стиле, ориентированном на удобство пользователей (UX) и высокую конверсию.

## 🚀 Особенности проекта

*   **Адаптивный дизайн (Mobile First):** Идеальное отображение на смартфонах, планшетах и широкоформатных мониторах (с использованием CSS Grid, Flexbox и fluid-типографики на базе `clamp()`).
*   **Высокая производительность:** Чистый HTML, CSS и ванильный JavaScript без тяжелых фреймворков.
*   **Bento-карточки:** Современный подход к верстке блоков для подачи сложной информации.
*   **Интерактивность:** Плавные микроанимации, кастомные курсоры, слайдеры (Swiper.js) и всплывающие окна (Модалки).
*   **SEO-Ready:** Семантическая верстка, правильная структура заголовков (H1-H3), мета-теги и разметка Schema.org для локального поиска.

## 📂 Структура проекта

```text
📁 estem-redesign
├── 📄 index.html          # Главная страница клиники
├── 📄 services.html       # Общий каталог услуг
├── 📁 aesthetic           # Раздел "Эстетика" (отбеливание, гигиена)
├── 📁 gnathology          # Раздел "Гнатология" (лечение суставов ВНЧС)
├── 📁 implants            # Раздел "Имплантация" (All-on-4, All-on-6)
├── 📁 orthodontics        # Раздел "Ортодонтия" (Брекеты, элайнеры)
├── 📁 orthopedics         # Раздел "Ортопедия" (Коронки, протезирование)
├── 📁 therapy             # Раздел "Терапия" (Лечение кариеса под микроскопом)
├── 📁 veneering           # Раздел "Виниры" (Композитные и керамические виниры)
├── 📁 css                 # Стили проекта (global.css, hero.css, bento.css и др.)
├── 📁 js                  # Скрипты (модальные окна, слайдеры, навигация, валидация форм)
└── 📁 img                 # Изображения, иконки, видео и SVG-графика
```

## 🛠 Технологии

*   **HTML5**
*   **CSS3** (CSS Variables, Flexbox, Grid, Clamp)
*   **JavaScript (Vanilla)**
*   **Swiper.js** (для каруселей и слайдеров отзывов)

## 📱 Особенности разработки

*   Формы заявок строго валидируют номера телефонов под казахстанский формат (`+7 (7XX) XXX XX XX`).
*   Внедрены media queries для адаптации интерфейса под различные брейкпоинты (`1360px`, `1024px`, `992px`, `768px`).
*   Сайт полностью подготовлен к деплою на любой статический хостинг (Vercel, Netlify, GitHub Pages) или классический сервер.
